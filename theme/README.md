# Docszine

A curated WordPress **Classic Theme** for issue-based editorial magazines and long-form humanities publishing.

## Requires

- WordPress 6.6+
- PHP 8.0+
- Recommended editing environment: Classic Editor

## WordPress-native content model

- Article → Post
- Author → User
- Section → Category
- Topic → Tag
- Images / captions / galleries → native Media Library
- Issue → the only custom taxonomy, supplied by the companion plugin

## Theme-managed presentation

- Magazine homepage
- Issue archive
- Long-form single article layout
- Category / Tag / Author archives
- Standard page, posts index, archive, search, 404 and comments
- Responsive Issue sidebar and on-page TOC
- Primary and Footer menu locations
- Custom Logo support
- Minimal Footer Customizer option

The Theme never registers the Issue taxonomy or editorial data. An optional companion plugin may provide publication-specific Issue metadata on Docszine sites, but it is not required by the theme. If the plugin is disabled, ordinary WordPress posts/pages and native archives continue to render without fatal errors.
