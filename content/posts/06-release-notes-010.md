Docszine 0.1.0 is the first independent build of this publication system. It keeps the original reading model while changing the identity, namespace, package structure, and editorial vocabulary to Docszine.

## Included in the first build

- A WordPress Classic Theme with homepage, Issue, article, archive, search, author, page, comments, and 404 templates.
- Responsive Issue navigation and an article table of contents.
- A separate Docszine Editorial plugin for Issue metadata, article order, homepage selections, and reading shortcodes.
- Safe fallback behavior when the plugin is inactive.

## Known boundaries

This is a production candidate in progress, not a public marketplace release. Browser compatibility, keyboard review, content migration, and deployment on the `docszine` subsite still need to be verified.

## Why publish the system itself

The best test for a publishing theme is a real archive with a reason to exist. Docszine will use its own Issue, pages, posts, and release notes to make the design decisions inspectable.
