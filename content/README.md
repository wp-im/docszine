# Docszine seed content

这是一套用于第一次建设 Docszine 自身站点的本地内容种子。它只描述和保存内容，不会自动写入 WordPress。

## 内容清单

- Pages：Home、About Docszine、Editorial Principles、Archive、Contact（5）
- Sections / Categories：Essays、Methods、Field Notes、Reviews（4）
- Topics / Tags：Classic Themes、Editorial Design、WordPress、Publishing（4）
- Issue：Issue 01 — The Reading Surface（1）
- Posts：6 篇，全部属于 Issue 01，并设置了 Issue 内顺序

## 写入约定

- 首页使用 `home.md` 作为静态首页内容；其余页面使用同名文件。
- `posts/` 中的 Front Matter 是建议的 WordPress 字段映射，不是运行时依赖。
- 首期无外部图片依赖，保证主题在没有 Media Library 素材时也能完整展示。
- 正式写入线上前，需要逐项确认这 5 个页面、6 篇文章和 1 个 Issue 的最终文本及数量。
