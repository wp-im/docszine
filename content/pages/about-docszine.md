# About Docszine

Docszine is an independent document-led magazine and a working example of a WordPress Classic Theme.

We are interested in long-form reading without unnecessary ceremony. An article should have a clear beginning, a navigable middle, and a useful way to continue. An issue should feel like a collection, not a folder of unrelated links.

The site is designed around native WordPress content: posts, pages, categories, tags, media, menus, and authors. A small companion plugin adds only the publication data that a theme cannot safely own, such as Issue metadata and editorial order.

This separation is practical as well as philosophical. Content should survive a change of appearance. Presentation should be able to become more precise without rewriting the archive.
