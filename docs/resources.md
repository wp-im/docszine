## 字体、图标与媒体

- 主题只使用系统字体栈，不下载 Google Fonts 或其他远程字体。
- 主题没有第三方图标库；菜单、箭头、关闭和树节点图形由 CSS/可访问文本表达。
- 主题没有内置照片、人物图像、音频、视频或第三方品牌资产。
- 主题截图中的示例文字和几何 artwork 是 Docszine 项目展示内容，不代表第三方出版物。
- 真实文章媒体由站点管理员通过 WordPress Media Library 提供，不属于主题发布包。

## 参考资料边界

`reference/field-notes-magazine/`、`reference/field-notes-magazine-1.0.1.zip` 和 `reference/static-html/` 是项目研究底稿，不是 Docszine 主题资源，不进入主题 ZIP，也不作为公共主题运行时依赖。

## 发布前复核

- [ ] 每个新增图片、字体、图标和库都追加到本表；
