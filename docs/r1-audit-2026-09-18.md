## 结果

## 线上部署链路

1. 在 Network Admin 主题上传页上传本地 0.2.0 ZIP。
2. WordPress 显示已安装 0.1.2、上传包为 0.2.0 后，确认 Replace installed with uploaded。
3. Network Themes 显示 Docszine 0.2.0 与 Network Disable，证明主题已网络启用。
4. 子站 `/docszine/wp-admin/themes.php` 显示 Active: Docszine，证明子站已激活。
5. 复核线上首页、菜单、文章 TOC、移动菜单和移动右栏后，将浏览器恢复到默认视口并停留在 Docszine 首页。
