A small companion plugin for Docszine publication metadata and editorial tools.

== Description ==

Docszine Editorial is a companion plugin for the Docszine Classic Theme.

It supplies the optional Issue taxonomy, Issue term metadata, post order, homepage editorial settings, and four safe Classic Editor shortcodes:

- `[docszine_note title="Note"]...[/docszine_note]`
- `[docszine_context title="Context"]...[/docszine_context]`
- `[docszine_definition term="Term"]...[/docszine_definition]`
- `[docszine_figure id="123" layout="margin"]`

The plugin does not register a Custom Post Type. Ordinary WordPress Posts, Users, Categories, Tags, and Media Library items remain the content model.
